# AIGC-skill

> 可用于 OpenClaude 或 Cursor（推荐使用 Cursor）

**重要提醒：处理后的文本请务必人工检查，删除口语化表达（如"说白了"等）**

将 AI 生成的文本转化为具有真实"认知痕迹"的高信息密度学术写作，有效降低 GPTZero、Turnitin 等 AI 检测工具的识别率。

---

## 适用场景

### 适合使用

| 场景 | 说明 |
|:---|:---|
| **学术论文改写** | 处理 AI 生成的论文草稿，降低学术不端检测风险 |
| **技术文档优化** | 让技术文档、报告更接近人工撰写风格 |
| **申请材料处理** | 个人陈述、研究计划等需要展现个人思考的文书 |
| **文献综述润色** | 将 AI 生成的综述转化为更有深度的表达 |

### 不适合使用

| 场景 | 原因 |
|:---|:---|
| 口语化改写 | 本身就是需要避免的 |
| 文学创作 | 需要原创性表达，不适用 |
| 随意聊天 | 无需刻意降低检测率 |
| 法律/医疗等专业文献 | 需要严格准确性，不建议改动 |

---

## 快速开始

### 方法一：直接使用（推荐）

将需要处理的文本直接粘贴到支持该 Skill 的 AI 对话中，Skill 会自动识别并激活处理。

### 方法二：手动调用

在提示词中明确说明：

```
请使用 AIGC-skill 处理以下文本，降低其 AI 检测率：
[在此粘贴你的文本]
```

---

## 核心能力

| 能力 | 具体效果 |
|:---|:---|
| **框架重构** | 将"八股文"结构转为问题驱动/辩驳型/材料驱动/自我反思型 |
| **词汇替换** | 删除 AI 高频词（Furthermore、值得注意的是、综上所述等），替换为精炼学术表达 |
| **句式调整** | 插入破折号、设问句、限定条件，打破 AI 的"平滑"句式 |
| **节奏控制** | 短句与长句交替，禁止连续相同结构 |

---

## 输入要求

- 任何需要处理的文本段落均可
- 支持中英文混合内容
- 建议单次处理不超过 2000 字，效果最佳

---

## 输出特点

- **高信息密度**：每句话承载有效信息，无填充词
- **学术审慎**：使用"可能""在X条件下"而非"显然""毫无疑问"
- **保留原意**：不改动核心数据、引用、结论
- **无前缀后缀**：直接输出改写后的纯文本

## 示例

### 输入（AI 特征明显的文本）

> 研究结果显示，社交媒体使用对青少年心理健康有显著的负面影响。因此，家长监控屏幕时间具有重要意义。总之，本研究为政策制定提供了确凿证据。

### 输出

> 我的分析指向一个关联——尽管只能审慎给出——社交媒体使用或许多少会影响青少年心理健康，至少在我所调查的群体（14-16岁，单一城市样本）中如此。话虽如此，有一个发现让我意外：控制睡眠质量后，上述关联几乎消失。这暗示真正问题或许不在屏幕本身，而在它挤占了什么。尚不明确的是因果方向：睡眠差导致更多刷屏，还是反过来？我的数据无法给出定论。不过，即便只是初步的，一个值得留意的实践启示是：家长与其严控时长，不如将重点放在稳定作息上。
